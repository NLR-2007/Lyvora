# 🎓 Skill Module - DBMS & Database Design

Welcome to the **Skill Module** of the DBMS & Database Design repository. This module focuses on fundamental database concepts, theoretical paradigms, and core competencies required for modern database management systems.

---

## 📌 Module Overview

This section is dedicated to structured learning, key concepts, schema design principles, and query optimization techniques.

### Key Focus Areas

1. **Relational Database Management Systems (RDBMS)**
   - Entity-Relationship (ER) & Enhanced ER (EER) Modeling
   - Relational Algebra & Calculus
   - Functional Dependencies & Normalization (1NF, 2NF, 3NF, BCNF, 4NF, 5NF)

2. **Structured Query Language (SQL)**
   - Data Definition Language (DDL)
   - Data Manipulation Language (DML)
   - Data Control Language (DCL) & Transaction Control Language (TCL)
   - Complex Joins, Subqueries, CTEs, and Window Functions

3. **Transaction Management & Concurrency Control**
   - ACID Properties (Atomicity, Consistency, Isolation, Durability)
   - Lock-based Protocols & Two-Phase Locking (2PL)
   - Timestamp Ordering & Multiversion Concurrency Control (MVCC)
   - Deadlock Detection and Prevention Mechanisms

4. **Storage Architecture & Indexing**
   - File Organizations & Buffer Pool Management
   - B-Trees, B+ Trees, and Hash Indexing
   - Query Execution, Optimization, and Execution Plans
